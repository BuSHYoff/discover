# Discover.

Discover. L’app qui te fait découvrir de nouvelles passions.

Découvre des passions inattendues, passe à l’action, progresse pas à pas. Discover met l’envie au premier plan et rend le démarrage facile, même sans expérience.

## Ce qui rend l’app unique

- Catalogue de passions riche et soigné, avec descriptions et tags.
- Parcours progressifs pour démarrer vite et progresser sans friction.
- Ressources fiables et cliquables pour aller plus loin.
- Expérience visuelle chaleureuse et immersive.


## Stack technique

- Flutter (Android, iOS, Web).
- Firebase Auth, Firestore.
- Google Sign-In.
- Shared Preferences.
- URL Launcher pour les ressources externes.

## Démarrage rapide

```bash
flutter pub get
flutter run
```
